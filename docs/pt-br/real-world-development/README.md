Explore o GitHub Copilot ao longo do ciclo de vida de desenvolvimento de software com cenários realistas, um aplicativo completo e um backlog compartilhado. Você trabalhará de forma iterativa para planejar mudanças, criar código, testar o comportamento, revisar pull requests e gerenciar tarefas com agentes.

## Cenário

Você é uma nova pessoa desenvolvedora na Tailspin Toys, uma empresa fictícia que financia jogos de tabuleiro com temática de programação. O backlog da equipe já está registrado como issues do GitHub e pronto para você escolher. Ele inclui recursos como filtragem e paginação, além de melhorias de qualidade, como acessibilidade e padrões de código.

## Escolha seu ambiente

O GitHub Copilot acompanha você onde quer que trabalhe. Escolha o ambiente adequado à forma como deseja desenvolver. Cada workshop começa com sua própria configuração e usa o cenário compartilhado da Tailspin Toys.

### [GitHub Copilot CLI][cli]

Use a interface de linha de comando (CLI) do GitHub Copilot para trabalhar com o assistente baseado em agentes no terminal. Explore os modos Plan e Autopilot, instruções, skills, agentes personalizados, Model Context Protocol (MCP) do Playwright, Agent Merge e comandos de barra práticos.

### [Aplicativo GitHub Copilot][app]

Execute sessões paralelas de agentes, alterne os modos de sessão, colabore em canvases e gerencie issues e pull requests do GitHub no aplicativo para desktop.

### [Agente de nuvem do GitHub Copilot][cloud]

Atribua issues do GitHub a um agente assíncrono, oriente o trabalho, acompanhe o progresso e revise os pull requests que ele abrir.

### [Visual Studio Code][vscode]

Use o GitHub Copilot no Visual Studio Code e no GitHub Codespaces. Trabalhe com o modo de agente do Copilot Chat, servidores MCP e agentes personalizados sem sair do editor.
